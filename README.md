# LinkedIn Posts — Style Guide

This repo captures **how I write LinkedIn posts**, distilled from 123 substantive posts (May 2019 → March 2026) in `Shares.csv` and from two reference cards I made (one showing what NOT to do, one showing the good structure).

## Files

| File | What it covers |
|------|----------------|

| [`good_approaches.md`](./good_approaches.md) | The 6-block skeleton + pre-flight checklist |
| [`tone_of_voice.md`](./tone_of_voice.md) | Voice attributes, signature phrases, register by topic |
| [`length_and_structure.md`](./length_and_structure.md) | Length stats + 6 structural archetypes |

| [`Shares.csv`](./Shares.csv) | Raw LinkedIn export (the source data) |

## Headline profile (TL;DR)

- **Default length: 600–1,000 characters** (median 676, mean 739).
- **Open with an emoji + a `𝗯𝗼𝗹𝗱` headline noun.** Never `Pleased to share…`.
- **One idea per short paragraph (1–3 lines)** with a meaningful emoji as the anchor.
- **3–5 inline hashtags**, not a bottom hashtag block.
- **Links go in the FIRST COMMENT.** Point to it with `👇🏻`.
- **Acks at the BOTTOM**, opened with `🙏🏻`.
- **Languages: ~60% English, ~40% Italian.** Never mix inside one post.
- **Media: GIF > photo > video.**

## How to use this when generating a new post

1. Identify the post type from the context I provide → pick a template in `post_templates.md`.
2. Apply the structural rules from `good_approaches.md`.
3. Calibrate length and paragraph count via `length_and_structure.md`.
4. Pick emojis from the palette in `emoji_usage.md`.
5. Run the pre-flight checklist in `good_approaches.md` before returning the post.
6. Cross-check against `bad_approaches.md` — none of the 10 anti-patterns should be present.
