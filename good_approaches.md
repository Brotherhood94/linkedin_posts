# Good Approaches — The structure that works for my LinkedIn posts

Derived from my "good structure" reference card and confirmed against my best-performing posts (the QKNN post, the QRAM preprint, the agentic-web essay).

---

## The 6-block skeleton

Every well-built post follows this order. Each block has a fixed role.

| # | Block | Role | Length |
|---|-------|------|--------|
| 1 | **Media** (GIF preferred) | Stops the scroll | n/a |
| 2 | **Title** | One short line, emoji-first, bold noun | 1 line |
| 3 | **Info** (body) | The substance — what / why / how | 3–8 short paragraphs |
| 4 | **Acks** | Tag co-authors / collaborators | 1–3 lines |
| 5 | **CTA** | Question + pointer to first comment | 1–2 lines |
| 6 | **Link** | In the FIRST COMMENT, never in the post | n/a |

---

## Block 1 — The Media (visible "above" the post)

- **Always use a GIF if possible.** A light loop draws attention without demanding play time.
- **Avoid static photos.** Especially avoid lab-team shots or anything with extraneous subjects (e.g. a cat on top of the lab equipment).
- **Avoid videos** — they need a deliberate play and many users won't bother.
- The media should communicate the IDEA, not the people behind it.
- For technical content: a diagram-style GIF showing the concept in 2–4 frames works very well.

---

## Block 2 — The Title (1 line, emoji-first)

**Template:**
```
<EMOJI> <Short headline with key noun in 𝗯𝗼𝗹𝗱>
```

**Working examples from my own history:**
- `🎊 My (old) first work is out! Quantum K Nearest Neighbor`
- `🎊 𝗡𝗲𝘄 𝗽𝗿𝗲𝗽𝗿𝗶𝗻𝘁 𝗶𝘀 𝗼𝘂𝘁! 🎊`
- `🔥 New job position! Postdoctoral Researcher on Quantum Algorithms at the Università di Pisa!`
- `🐘 L'elefante nella stanza della computazione quantistica`
- `✨ What an amazing ride it has been!`

**Rules:**
- First character is ALWAYS an emoji.
- One line only. If it wraps to two lines on desktop, it's too long.
- Use bold unicode (`𝗯𝗼𝗹𝗱`) on 1–3 key words.
- For event recaps / emotional posts, use a feeling-first opener (`✨`, `🎊`, `❤️`).
- For research drops, use a "ship-it" opener (`🎊`, `🚀`, `🔥`).
- For provocative essays, use a punchy / metaphorical opener (`🐘`, `🤯`, `🌐🤖`).

---

## Block 3 — The Info (the body)

This is the substance. Most posts follow one of two body shapes.

### Shape A — "Research / project drop" (with 🟣 bullets)

```
<EMOJI> One-line problem framing or motivation.

<EMOJI> One-line stake / why it matters.

In this work / On this episode / In our paper:
   🟣 First contribution / first topic;
   🟣 Second contribution;
   🟣 Third contribution.

<EMOJI> One-line takeaway or implication.
```

The `🟣` bullets are my signature for **enumerating contributions or topics** — used in ~10% of posts but always for "the list of points" pattern.

### Shape B — "Storytelling / explainer"

```
<EMOJI> Hook: a surprising or controversial statement.

<EMOJI> Context: what most people assume.

<EMOJI> Reveal: the counterintuitive fact / "elephant in the room".

(Soft italic aside in 𝘪𝘵𝘢𝘭𝘪𝘤 unicode — like a whispered thought)

<EMOJI> So what? The implication or "what changes now".

<EMOJI> Optional: tie it back to my work / our work.
```

### Universal rules for the body

- **Every paragraph starts with a meaningful emoji** that previews the content (🔬 for science, 🛠️ for engineering, 🎯 for goals, ⛔ for warnings, 💡 for insights, 🤔 for questions, 🚀 for impact).
- **Each paragraph is 1–3 lines max.**
- **Blank line between every paragraph** — whitespace is a feature.
- **Bold unicode (`𝗯𝗼𝗹𝗱`)** on the 1–3 most important concepts per paragraph.
- **Italic unicode (`𝘪𝘵𝘢𝘭𝘪𝘤`)** for asides, definitions, or quoted text.
- **Inline hashtags** on key nouns: `…the #parallelism of #quantum gates…` (not a hashtag block at the bottom).

---

## Block 4 — The Acks

Always near the bottom, opened with `🙏🏻` (or `🙏`).

**Templates:**
- `🙏🏻 Thanks to <Name1>, <Name2>, and <Name3>.`
- `🙏🏻 Huge thanks to <Name> for making me less "segalitico"!`
- `🤝🏻 Immense gratitude to my fellow co-organizers: <Names> — without you this would never have been possible.`

**Rules:**
- Tag the names so they get notified (it triggers likes from the tagged people).
- Keep the ack block SHORT — 1–3 lines.
- For big events, split into two ack blocks (organizers / speakers / staff / advisors), each with its own emoji.

---

## Block 5 — The CTA (question + pointer)

This is the part that drives engagement.

**Pattern 1: Pure question + first-comment pointer**
```
👀 Are you interested in quantum classifiers?
👇🏻 Then, take a look at this article in the first comment below!
```

**Pattern 2: Italic curiosity question + pointer**
```
🧐 Are you curious?
👇🏻 𝗜𝗳 𝘆𝗼𝘂 𝗮𝗿𝗲 𝘃𝗲𝗿𝘆 𝗰𝘂𝗿𝗶𝗼𝘂𝘀 about our work, in the first comment, you can find the arxiv's link!
```

**Pattern 3: Direct pointer (no question)**
```
👇🏻 link in the first comment!
```

**Rules:**
- `👇🏻` (pointing down + skin tone) is my signature CTA emoji. Used 34 times across my corpus.
- The question line is OPTIONAL but strongly preferred for research posts and explainers.
- For event recaps, replace the CTA with `❤️ See you soon!` style emotional closer.

---

## Block 6 — The Link (in the first comment)

- Always use a **shortened URL** (e.g., `bit.ly/3TxLj96` or `lnkd.in/...`) to track clicks.
- One link per post.
- After publishing the post, immediately post the link as the FIRST comment so it gets pinned to the top of the comment section.

## Stylistic conventions (quick reference)

| Convention | When | Example |
|------------|------|---------|
| Bold unicode `𝗯𝗼𝗹𝗱` | Key concepts | `𝗲𝗳𝗳𝗶𝗰𝗶𝗲𝗻𝘁𝗹𝘆 𝗽𝗿𝗲𝗽𝗮𝗿𝗲 𝗮 𝗾𝘂𝗮𝗻𝘁𝘂𝗺 𝘀𝘁𝗮𝘁𝗲` |
| Italic unicode `𝘪𝘵𝘢𝘭𝘪𝘤` | Asides, soft voice, quotes | `𝘠𝘦𝘴? ✅` / `𝘗𝘴𝘴! 𝘛𝘩𝘦𝘳𝘦 𝘪𝘴 𝘴𝘰𝘮𝘦𝘵𝘩𝘪𝘯𝘨 𝘧𝘰𝘳 𝘺𝘰𝘶...` |
| Inline hashtag | Highlight a noun mid-sentence | `the #parallelism of #quantum gates` |
| 🟣 bullet | Enumerate contributions/topics | `🟣 We study how...` |
| 👇🏻 + 🏻 skin tone | Pointing to first comment | `👇🏻 link in the first comment` |
| 🙏🏻 | Open the acks block | `🙏🏻 Thanks to ...` |
| 🤫 | Tease / hint at something hidden | `🤫 Psst! There is something for you...` |

## "Pre-flight check" before posting

Run through this list before hitting publish:

1. [ ] Title is ONE line and starts with an emoji?
2. [ ] Key noun in the title is in **bold unicode**?
3. [ ] Each paragraph starts with a meaningful emoji?
4. [ ] Paragraphs are short (1–3 lines) with blank lines between them?
5. [ ] 2–5 inline hashtags on highlighted nouns?
6. [ ] Acks at the BOTTOM (not top)?
7. [ ] At least one CTA: question OR `👇🏻 first comment`?
8. [ ] No raw URL in the post body? (Link goes to first comment.)
9. [ ] Media is a GIF, not a photo or video?
10. [ ] Total length between ~400 and ~1500 characters?
